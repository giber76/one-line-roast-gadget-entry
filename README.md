`main.ts` writes a single original roast line (118 characters) to `/output/entry.txt`:

> My alarm lets me snooze nine times, then acts shocked when I'm late, as if it wasn't sitting right there for all nine.

The roast targets the alarm app — a gadget/app used every day — with a concrete detail (nine snoozes) and a fresh angle: the app is a witness that pretends to be a bystander.
